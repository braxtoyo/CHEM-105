# CHEM 105 — TI-84 Plus CE programs

| Folder | What's in it | Send to calculator |
|---|---|---|
| [`midterm1/`](midterm1/) | Midterm 1 notes + tools: `CHEM` menu, FULL NOTES (`CHFULL`, `CHF1`–`CHF10`), exam setup (`CHPS`), unit converter (`CHCV`), isoelectronic list, electron config | everything in `midterm1/8xp/` |
| [`midterm2/`](midterm2/) | Midterm 2: `MIDTERM2` menu, SN+LP shape solver (`MT2SN`), Lewis solver (`MT2LW`), shared geometry (`MT2G`), VSEPR, σ/π/MO, bands, ions, isomers, theories | everything in `midterm2/8xp/` |

Each folder has its own README, source, and `build.py` (run it inside that folder; needs `pip install tivars`).
The two sets use different program names, so both can live on the calculator at once.
